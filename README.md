# E-commerce Sales Dashboard | Power BI

## 📌 Project Overview
Developed an interactive E-commerce Sales Dashboard using Power BI to analyze 3,500+ sales transactions and identify key trends in revenue, profitability, product performance, and regional sales. Transformed raw data into actionable business insights through data cleaning, data modeling, DAX measures, and interactive visualizations to support data-driven decision-making.

## 🛠️ Technical Implementation

**Data Cleaning & Transformation**
- Used Power Query Editor to clean and transform raw sales data.
- Standardized date formats and handled inconsistent data values.
- Created Month and Year columns to support time-based analysis.

**Data Modeling & DAX**
- Built relationships between relevant data tables where required.
- Created DAX measures to calculate total sales, total profit, profit margin, and other key performance indicators.
- Used aggregation functions to analyze business performance.

**Interactive Dashboard & Visualizations**
- **KPI Cards:** Displayed Total Sales, Total Profit, Profit Margin, and Top-Performing Product.
- **Line Charts:** Analyzed monthly sales trends and fluctuations.
- **Bar and Column Charts:** Compared product and category performance.
- **Regional Analysis:** Evaluated sales and profitability across regions.
- **Slicers:** Enabled interactive filtering by region, category, and date.

## 📊 Key Business Insights
- **Top-Performing Category:** Electronics generated the highest revenue among the analyzed product categories.
- **Leading Product:** Cameras emerged as a major revenue contributor.
- **Regional Performance:** The West Region recorded the highest sales performance, highlighting its importance to overall business revenue.
- **Sales Trends:** Identified monthly fluctuations and potential seasonal patterns to support inventory and sales planning.
- **Business Opportunities:** Regional and product-level comparisons revealed areas for targeted marketing and improved sales performance.

## 📂 Project Structure
- `ecommerce_sales_data.csv` – Raw dataset used for analysis.
- `Ecommerce_Sales_Dashboard.pbix` – Power BI dashboard file.
- `Images/` – Dashboard screenshots for preview.
- `README.md` – Project documentation and key findings.

## 🚀 How to Run the Project
1. Download or clone this GitHub repository.
2. Open `Ecommerce_Sales_Dashboard.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the location of `ecommerce_sales_data.csv`.
4. Select **Home → Refresh** to load the latest data.
5. Explore the dashboard using KPI cards, charts, and slicers to analyze sales, profit, products, categories, regions, and monthly trends.
